# PiFi Enterprise Router - Windows 運用ガイド

本ルーター管理システムは、Windows 10 / 11 上でネイティブ動作するように設計されています。
Windows のネットワークインターフェース（Wi-Fi、イーサネット、仮想NIC）の自動検出、`netsh` によるポートプロキシ転送、`arp -a` によるクライアント検出に対応しています。

---

## 1. 事前準備 (必要な環境)

1. **Node.js (v18.0.0 以上、v20 または v22 LTS 推奨)**
   - [公式サイト (nodejs.org)](https://nodejs.org/) よりインストーラー（LTS版）をダウンロードしてインストールしてください。
   - インストール確認 (PowerShell または コマンドプロンプト):
     ```cmd
     node -v
     npm -v
     ```

2. **Git (任意・推奨)**
   - ソースコードの取得に使用します。

---

## 2. 起動手順

### 方法A: バッチファイルからワンクリック起動 (推奨)
1. プロジェクトフォルダ内にある **`start-windows.bat`** を右クリックします。
2. **「管理者として実行」** を選択します。
   *(※管理者権限で実行することで、Windows の `netsh` ポート転送や Wi-Fi 設定のフル機能が有効になります)*
3. 依存ライブラリの自動チェックが行われ、開発サーバーが起動します。

---

### 方法B: コマンドプロンプト / PowerShell から手動起動

1. **PowerShell** または **コマンドプロンプト** を **「管理者として実行」** で開きます。
2. プロジェクトのディレクトリに移動します:
   ```cmd
   cd C:\path\to\pifi-router
   ```
3. 初回のみ依存関係をインストールします:
   ```cmd
   npm install
   ```
4. サーバーを起動します:
   ```cmd
   npm run dev
   ```
   *(※本番ビルドで実行する場合は `npm run build` を実行後、`npm start`)*

---

## 3. ブラウザでのアクセス

起動後、お好みのブラウザ（Chrome, Edge, Firefox 等）で以下を開きます:

- **ルーター管理コンソール**:  
  👉 **`http://localhost:3000`**
- **初期管理者ログイン情報**:
  - ユーザー名: `admin`
  - パスワード: `admin`
- **キャプティブポータル認証画面**:  
  👉 **`http://localhost:3000/portal`** (または `http://pifi.me/login`)

---

## 4. Windows での WAN / LAN インターフェース設定手順

Windows 環境では、有線LAN（イーサネット）と無線LAN（Wi-Fi）など、接続されているアダプターを用途に応じて自由に割り当て可能です。

1. サイドメニューの **「LAN / 無線設定」** をクリックします。
2. 画面上部の **「WAN / LAN インターフェース割り当て設定 (Interface Mapping)」** を確認します。
3. **WAN (インターネット受信用)**:
   - 例: 自宅ルーターに接続されている `Wi-Fi` アダプターや `イーサネット` をプルダウンから選択します。
4. **LAN (ローカル配信用)**:
   - 例: クライアントPCに接続されている有線LANやUSB-LANアダプターを選択します。
5. **「インターフェース設定を適用」** ボタンをクリックします。
   - 設定が即時保存され、ダッシュボードやCLIモニターに反映されます。

---

## 5. Windows 固有のポイント・トラブルシューティング

### ① 管理者権限が必要な機能について
- ポートフォワーディング（ポートプロキシ）の追加・削除
- 一部の `netsh wlan` コマンド
- **対処法**: コマンドプロンプトや VSCode、PowerShell を必ず **「管理者として実行 (Run as Administrator)」** してください。

### ② Windows Defender ファイアウォールの許可
- 起動時に「Windows セキュリティの重要な警告 (Node.js の通信を許可しますか？)」というポップアップが表示された場合は、**「プライベート ネットワーク」にチェックを入れて [アクセスを許可する]** を選択してください。

### ③ ポート 3000 が既に使われている場合
- 別のアプリがポート 3000 を使用している場合は、環境変数でポート番号を変更できます:
  ```powershell
  # PowerShell の場合:
  $env:PORT = "3001"
  npm run dev
  ```
  ```cmd
  # コマンドプロンプトの場合:
  set PORT=3001
  npm run dev
  ```
